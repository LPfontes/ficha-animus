# 🌌 ANIMUS - Gerador de Ficha RPG

![Versão](https://img.shields.io/badge/Vers%C3%A3o-Beta-purple)
![React](https://img.shields.io/badge/React-19-blue)
![Vite](https://img.shields.io/badge/Vite-8-yellow)

**ANIMUS** é uma ferramenta digital avançada projetada para jogadores e mestres do sistema **Animus RPG**. Com uma interface moderna baseada em *glassmorphism* e foco em usabilidade, o gerador automatiza cálculos complexos e facilita a criação e gestão de personagens.

---

## ✨ Funcionalidades Principais

- **🎭 Gestão de Perfil Completa**: Definição de nome, nível, ascendência e afinidade elemental com bônus automáticos.
- **📊 Atributos e Status Dinâmicos**: Cálculos automáticos de Pontos de Vida (PV), Energia (PE), Ações (PA) e Proteção baseados em atributos e equipamentos.
- **⚔️ Arsenal de Combate**: Gerenciador de armas e armaduras com cálculo de dano e transparência total nas fórmulas.
- **🧪 Calculadora Elemental**: Módulo dedicado para magia e efeitos elementais.
- **🎒 Inventário Inteligente**: Controle de itens e carga.
- **✨ Talentos e Perícias**: Sistema de seleção de talentos com modais intuitivos e gestão de pontos de habilidade.
- **📸 Customização Visual**: Upload e recorte de imagem para o retrato do personagem.
- **📄 Exportação**: (Em desenvolvimento) Suporte para geração de PDF da ficha completa.

---

## 🚀 Tecnologias Utilizadas

O projeto utiliza o que há de mais moderno no ecossistema web para garantir performance e estética:

- [React](https://reactjs.org/) - Lógica de interface reativa.
- [Vite](https://vitejs.dev/) - Tooling ultrarrápido para desenvolvimento.
- [Lucide React](https://lucide.dev/) - Conjunto de ícones vetoriais elegantes.
- [React Easy Crop](https://www.npmjs.com/package/react-easy-crop) - Ferramenta de manipulação de imagens.
- [Vanilla CSS](https://developer.mozilla.org/en-US/docs/Web/CSS) - Design system customizado com foco em Glassmorphism e UX premium.

## 🛠️ Instalação e Execução

Para rodar o projeto localmente, siga os passos abaixo:

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/LPfontes/ficha-animus.git
   cd animus-generator
   ```

2. **Instale as dependências:**
   ```bash
   npm install
   ```

3. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

4. **Acesse no navegador:**
   O Vite informará a porta (geralmente `http://localhost:5173`).
